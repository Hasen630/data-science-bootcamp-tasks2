# Statistical Engineering & Simulation

## Overview
This project implements a custom statistical engine in pure Python and a Monte Carlo simulation to demonstrate the Law of Large Numbers.

## Part 1: Statistical Engine
Implemented from scratch:
- Mean
- Median
- Mode (including multimodal handling)
- Variance (sample and population)
- Standard deviation
- Outlier detection

Includes robust error handling for invalid and empty datasets.

## Part 2: Simulation
A Monte Carlo simulation was built to model a server crash probability of 4.5%.

The simulation was run for:
- 100 days
- 1,000 days
- 10,000 days

## Key Insight
As the number of simulations increases, the estimated probability converges to the true value (Law of Large Numbers).

## Conclusion
Small datasets produce unreliable estimates due to randomness, making them risky for decision-making.
